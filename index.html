Summary Table Prototype

A working sketch of the three-step SLP workflow, built in about three hours as a job-application work sample. Step 2 is the part that is built. Everything runs in this page: nothing is stored or sent.

1. Choose the sources you plan to gather

Each source you pick becomes a row in step 2. To see what a set of sources covers, use the official Source Complementarity Matrix. It is shared under a no-derivatives licence, so this prototype links to it rather than rebuilding it (open question Q5).

2. Code each source on its own

Reduce each source to what it showed, then answer Disorder? for that source alone. Only Yes and No count toward convergence. An inconclusive source needs a one-line reason and is left out of the count.
